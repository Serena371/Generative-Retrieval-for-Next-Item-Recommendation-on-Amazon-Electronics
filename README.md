# Generative-Retrieval-for-Next-Item-Recommendation-on-Amazon-Electronics
Next-item recommendation on 1M Amazon Electronics interactions comparing Popularity, NCF and TIGER generative retrieval (semantic IDs via RQ-VAE + T5; HR@10 0.594 vs. 0.528 NCF), plus a grounded shopping agent using a local LLM (Qwen3 via Ollama) that searches the catalog and verifies prices and reviews before answering.
